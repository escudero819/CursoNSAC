FLUJO DE DATOS:
1. EQUIPO consulta /eventos -> lee de SQLite (rápido, sin internet)
2. SINCRONIZAR -> requests consulta NASA -> pandas transforma -> SQLAlchemy guarda en SQLite
3. ESTADÍSTICAS -> SQLAlchemy lee SQLite -> pandas calcula métricas -> devuelve JSON
4. EXPORTAR -> SQLAlchemy lee SQLite -> pandas exporta CSV
