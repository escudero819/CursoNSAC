Recursos de la clase 3 - Exportar a SQL

Al ejecutar `app.py`, se creará automáticamente:
- `datos_nasa.db`: Base de datos SQLite con la tabla `asteroides`.
- `asteroides_procesados.csv`: (opcional) exportación a CSV.

Puedes inspeccionar la base de datos con:
- DB Browser for SQLite (gratuito)
- Extensión SQLite en VS Code
- Python con sqlite3 o SQLAlchemy
